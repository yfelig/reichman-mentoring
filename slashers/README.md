# Slashers — Tech Troop

Practical business incubator by Tech Troop. Yair + Rivka enrolled together, working on KlafLi as the project.

**Program:** https://tech-troop.co.il/freelancers/
**Duration:** 10 weeks (Wednesdays 5–7:30 PM, online)
**Cohort:** 40 participants per cycle
**Cost:** Fully subsidized — 500 NIS refundable deposit

## What It Is

A structured incubator for building an independent income stream. Three phases:

1. **Orientation** — validate the idea, research the market, define the value proposition
2. **Business Development** — legal registration, pricing model, first sales (25% generate income at this stage)
3. **Growth** — operations, AI tools, client presentation, scaling

Weekly meetings + 5+ hrs independent work per week. Goal: first revenue before the program ends.
